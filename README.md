# Doumi — Web Kemitraan (Next.js)
1. `npm install`
2. `cp .env.example .env.local` lalu pilih `AI_PROVIDER` (xai/gemini/anthropic) dan isi key-nya
3. `npm run dev` → http://localhost:3000

Edit konten di `lib/data.ts` (dipakai web & chatbot). Nomor WA: `WA_NUMBER`.
Tambahkan foto/logo dari PDF ke folder `public/` bila diperlukan.
